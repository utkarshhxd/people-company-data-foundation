01 / full pipeline

The spine, the quarantine loop, and the AI-proposal loop

One file, dropped or fed by hand, moving left to right through six stages before it becomes a golden value. Two loops peel off and rejoin: quarantine underneath validation, and the AI enrichment queue underneath resolution. The review console touches all four queues at once — scroll to see where.

viewBox 2200 × 1000 · scroll horizontally on narrow screens 10 numbered edge cases ↓ explained below

1
Ingestion
Type inference is off, everywhere. Every cell lands as a string, verbatim. A spreadsheet reader silently turning "007" into 7 would be unrecoverable data loss before anyone even decided what the column meant.
2
Ingestion
Duplicate loads are blocked, races are not. payload_hash stops the same file loading twice; a separate in-flight check (find_in_flight_batch) closes the race where two processes ingest the same file concurrently.
3
Mapping
Value-based guesses can never auto-accept. value_analysis is hard-capped at 0.75 confidence — values prove a type, not a field. And if two columns both look like the same field, both drop to needs_review; no silent winner gets picked.
4
Normalization
Unmapped columns are captured too. attribute_observation writes one row per source column per row — including columns nobody has reviewed yet — so nothing is lost while a mapping decision is still pending.
5
Any stage
A bug and a bad value are not the same failure. record_error catches malformed payloads and constraint violations — our fault, happening before a row can even become a proper record — kept structurally separate from quarantine, which is a verdict about the data itself.
6
Quarantine
Only a record-scope error invalidates the whole record. An earlier version let any single attribute error take the record down — one broken Phone column once wrongly quarantined 907 of 1000 otherwise-good rows. Fixed by scoping invalidation to record-level errors only.
7
Resolution
Moderate evidence has a ceiling. If the best-matched identity key is only moderate strength, confidence is hard-capped at 0.89 — no amount of corroboration crosses it into auto-link. A tie at ≥0.90 between two candidates is forced to review instead of coin-flipped.
8
Resolution
source.describes changes what "same" means. A vendor cataloguing locations, not organisations, gets its domain/email keys demoted to moderate — a shared parent domain across storefronts shouldn't auto-merge them. Before this existed, a merge tool almost collapsed 5,097 distinct retail locations into one entity.
9
Golden Build
Losing values are never discarded. Every alternative stays in evidence.alternatives with its source. Rebuilds are idempotent — an unchanged winner keeps its original valid_from even when the builder reruns.
10
Enrichment
AI may propose, never assert. Nothing writes golden_attribute directly, ever — an accepted proposal becomes an ordinary source row and competes as evidence like any vendor. An early design that wrote straight through via a low-reliability synthetic source was rejected mid-build for breaking exactly this rule.
